# 바로복붙 개인정보처리방침

시행일: 2026년 5월 21일

바로복붙은 사용자가 자주 쓰는 문구를 저장하고, 버튼 또는 단축키로 복사하거나 현재 입력창에 삽입할 수 있도록 돕는 Chrome 확장 프로그램입니다.

## 1. 수집하는 정보

바로복붙은 다음 정보를 사용자의 브라우저 로컬 저장소(chrome.storage.local)에 저장합니다.

- 사용자가 직접 입력한 문구 제목
- 사용자가 직접 입력한 문구 내용
- 사용자가 설정한 단축키
- 사용자가 선택한 테마 색상

이 정보는 사용자의 기기 안에만 저장됩니다.

## 2. 수집하지 않는 정보

바로복붙은 다음 정보를 수집하지 않습니다.

- 이름, 이메일, 전화번호 등 개인 식별 정보
- 방문 기록
- 웹페이지 내용
- 로그인 정보
- 결제 정보
- 위치 정보
- 쿠키
- 클립보드에서 읽은 정보

## 3. 정보 사용 목적

저장된 정보는 다음 기능을 제공하기 위해서만 사용됩니다.

- 저장된 문구 목록 표시
- 문구 복사
- 단축키를 통한 문구 삽입
- 테마 색상 유지

## 4. 정보 저장 및 전송

바로복붙은 서버를 운영하지 않으며, 저장된 데이터를 개발자 서버나 외부 서비스로 전송하지 않습니다.

모든 데이터는 사용자의 Chrome 브라우저 로컬 저장소에만 저장됩니다.

## 5. 제3자 제공

바로복붙은 사용자의 데이터를 제3자에게 판매, 공유, 제공하지 않습니다.

## 6. 원격 코드 및 분석 도구

바로복붙은 원격 코드를 사용하지 않습니다.

Google Analytics 등 외부 분석 도구를 사용하지 않습니다.

## 7. 데이터 삭제 방법

사용자는 확장 프로그램 팝업에서 저장된 문구를 직접 삭제할 수 있습니다.

또는 Chrome에서 확장 프로그램을 삭제하면 브라우저에 저장된 관련 데이터도 함께 삭제될 수 있습니다.

## 8. 권한 사용

바로복붙은 기능 제공을 위해 다음 권한을 사용합니다.

- storage: 사용자가 저장한 문구, 단축키, 테마 설정을 로컬에 저장하기 위해 사용합니다.
- clipboardWrite: 사용자가 복사 버튼을 눌렀을 때 저장된 문구를 클립보드에 쓰기 위해 사용합니다.
- activeTab 및 scripting: 현재 활성 탭의 입력창에 저장된 문구를 삽입하기 위해 사용합니다.
- http/https 페이지 접근: 사용자가 일반 웹페이지 입력창에서 단축키로 문구를 삽입할 수 있도록 content script를 실행하기 위해 사용합니다.
